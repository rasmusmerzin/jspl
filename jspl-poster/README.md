## Printing to PDF

Run `npx serve .` to host the web page.

Use Chromium to print to PDF file:

1. Navigate to [`http://localhost:3000`](http://localhost:3000) in Chromium.
2. Press Ctrl+P (maybe Command+P on macOS) to print and use the following settings:
   - Layout: Portrait
   - Paper size: A0
   - Pages per sheet: 1
   - Margins: None
   - Scale: Custom 200
   - Options: Background graphics (checked)
